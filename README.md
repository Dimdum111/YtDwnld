## About
YtDwnld is an App to download Youtube Videos as Mp4/Mp3,  
It's written in python.

You can download Mp4/Mp3, It will store them in `YtDwnld Downloads`.  

You can even download entire playlists with it!  
Just input a link of a playlist (Or video in it) Into the URL bar and press `Download!` (Make sure that `Download entire playlist?` is selected)  
## How to use?
Just download an executable for your operating system from [Releases](https://github.com/Dimdum111/YtDwnld/releases), Extract it into a folder, and run it!

## Features
- Download YouTube videos as MP4
- Download audio-only as MP3
- Full playlist support
- Cross-platform (Windows/Mac/Linux)
